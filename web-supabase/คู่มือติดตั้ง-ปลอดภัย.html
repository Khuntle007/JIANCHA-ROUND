ชั้น 2 · เข้าระบบล็อกอินรายคน (ชื่อผู้ใช้+รหัส) · สิทธิ์แยกตามคน
ชั้น 3 · ซอร์สโค้ดrepo private + ไม่มี endpoint สาธารณะ
Part 1 · ฐานข้อมูล (Supabase)
1

สมัคร + สร้างโปรเจกต์

  • supabase.com → Start your project → New project
  • ตั้งชื่อ · ตั้ง Database Password (จดไว้) · Region Singapore → Create (รอ ~2 นาที)
2

รันสคริปต์ฐานข้อมูล

  • SQL Editor → New query → วางเนื้อ supabase-setup.sql
  • 🔑 เปลี่ยน 'JIANCHA-CHANGE-ME' เป็นรหัสผ่านของบัญชี adminที่ต้องการ → Run
ล็อกอินครั้งแรก: ชื่อผู้ใช้ admin + รหัสที่ตั้ง → จากนั้นเข้าเมนู สิทธิ์ผู้ใช้ สร้างผู้ใช้อื่น + เลือกสิทธิ์รายคนได้
3

คัดลอกค่า 2 ค่า

  • Project Settings → API → คัดลอก Project URL และ anon public key
ปลอดภัย: anon key เปิดข้อมูลไม่ได้ถ้าไม่มีรหัสผ่านองค์กร (ทุก endpoint บังคับรหัส)
Part 2 · ใส่ค่าในแอป + ขึ้น GitHub
4

ใส่ค่าในไฟล์

  • เปิด web-supabase/index.html ด้วย Notepad → แทนค่า 2 บรรทัดบนสุด:

const SUPA_URL = 'https://YOUR-PROJECT.supabase.co'; const SUPA_KEY = 'YOUR-ANON-PUBLIC-KEY';

  • Save → เปิด GitHub Desktop → กด Push origin
หรือส่งค่า 2 อย่าง (URL + anon key) มาให้ผมทางแชท เดี๋ยวผมใส่ให้แล้ว push ให้เลย
Part 3 · โฮสต์ (Cloudflare Pages)
5

เชื่อม repo กับ Cloudflare Pages

  • สมัคร cloudflare.com (ฟรี) → เมนู Workers & Pages → Create → แท็บ Pages → Connect to Git
  • อนุญาต GitHub แล้วเลือก repo JIANCHA-ROUND
6

ตั้งค่า build

  • Framework preset: None
  • Build command: (เว้นว่าง)
  • Build output directory: web-supabase ← สำคัญ! (ให้เสิร์ฟเฉพาะเวอร์ชันปลอดภัย)
  • กด Save and Deploy → ได้ลิงก์ https://xxxx.pages.dev
Part 4 · ล็อกให้เฉพาะพนักงาน (Cloudflare Access)
7

เปิด Zero Trust → Access

  • Cloudflare Dashboard → Zero Trust → Access → Applications → Add an application → Self-hosted
  • Application name: JIANCHA Rounds · Domain: ใส่ลิงก์ xxxx.pages.dev ของคุณ
8

ตั้ง Policy อนุญาตเฉพาะองค์กร

  • Policy name: Staff only · Action: Allow
  • Include → Selector: Emails ending in → @jianchatea.com
    (หรือ Selector Emails แล้วใส่รายชื่ออีเมลเฉพาะคน)
  • Save → เสร็จ! ต่อไปเปิดเว็บต้องยืนยันอีเมลองค์กรก่อน คนนอกเปิดไม่ได้แม้มีลิงก์
ผลลัพธ์: เปิดเว็บ = ยืนยันอีเมล @jianchatea.com → ล็อกอินรายคน → เห็นเฉพาะสิ่งที่ได้รับสิทธิ์ (ข้อมูลรวมศูนย์ ซิงก์ทุกเครื่อง)
