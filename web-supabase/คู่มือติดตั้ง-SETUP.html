JIANCHA · Rounds System

คู่มือติดตั้ง “เว็บจริง”

ทำครั้งเดียว ~15 นาที · ได้ลิงก์เปิดได้ทุกอุปกรณ์ ข้อมูลก้อนเดียวซิงก์กัน
ไฟล์ที่ใช้: index.html · supabase-setup.sql

1

สมัคร Supabase (ฟรี) + สร้างโปรเจกต์

  • ไปที่ supabase.com → กด Start your project → เข้าสู่ระบบ (ใช้ GitHub หรืออีเมล)
  • กด New project → ตั้งชื่อ (เช่น jiancha-rounds) → ตั้ง Database Password (จดไว้) → เลือก Region Southeast Asia (Singapore) → Create
  • รอสร้างเสร็จ ~2 นาที
2

รันสคริปต์สร้างฐานข้อมูล

  • เมนูซ้าย → SQL Editor → New query
  • เปิดไฟล์ supabase-setup.sql ด้วย Notepad → คัดลอกทั้งหมด → วางในช่อง
  • 🔑 หา บรรทัด 'JIANCHA-CHANGE-ME' แล้วเปลี่ยนเป็นรหัสผ่านผู้ดูแลที่คุณต้องการ
  • กด Run (ควรขึ้น Success)
3

คัดลอกค่าเชื่อมต่อ 2 ค่า

  • เมนูซ้าย → Project Settings (รูปเฟือง) → API (หรือ Data API)
  • คัดลอก Project URL (เช่น https://abcd1234.supabase.co)
  • คัดลอก anon public key (สายอักษรยาวขึ้นต้น eyJ...)
anon key เปิดเผยได้ ปลอดภัยโดยออกแบบ — การแก้ไขข้อมูลถูกล็อกด้วยรหัสผ่านผู้ดูแลที่ฝั่งเซิร์ฟเวอร์
4

ใส่ค่าลงไฟล์ index.html (แก้ 2 บรรทัด)

  • คลิกขวาที่ index.html → Open with → Notepad
  • ที่บนสุดของสคริปต์ หา 2 บรรทัดนี้แล้วแทนค่า:

const SUPA_URL = 'https://YOUR-PROJECT.supabase.co'; const SUPA_KEY = 'YOUR-ANON-PUBLIC-KEY';

  • วาง Project URL และ anon key แทนที่ → Save (Ctrl+S)
5

อัปขึ้นเว็บ → ได้ลิงก์จริง

  • ไปที่ app.netlify.com/drop
  • ลากไฟล์ index.html (ที่แก้แล้ว) ไปวางบนหน้านั้น
  • ได้ลิงก์ทันที เช่น https://ชื่อสุ่ม.netlify.app
ลิงก์แบบลากวางเป็นแบบชั่วคราว — สมัคร Netlify ฟรี (กด Sign up) เพื่อเก็บลิงก์ถาวร และตั้งชื่อ/โดเมนเองได้ภายหลัง
6

เปิดใช้งาน

  • เปิดลิงก์ → ใส่ รหัสผ่านผู้ดูแล (ที่ตั้งไว้ข้อ 2)
  • ครั้งแรกระบบจะโหลดสาขาเริ่มต้น 61 สาขาให้อัตโนมัติ
  • ข้อมูลถูกเก็บที่ Supabase → เปิดจากเครื่อง/มือถือไหนก็เห็นข้อมูลเดียวกัน
7

แชร์รายสาขา (เปิดได้โดยไม่ต้องล็อกอิน)

  • เปิดสาขา → ปุ่ม 🔗 แชร์ลิงก์สาขา → คัดลอกลิงก์ (เช่น .../?branch=JC004)
  • ใครเปิดลิงก์นี้จะเห็นเฉพาะสาขานั้น + ออเดอร์เดือนปัจจุบัน อ่านอย่างเดียว ไม่เห็นสาขาอื่น

ข้อควรรู้

  • เปลี่ยนรหัสผ่านผู้ดูแลภายหลัง: Supabase → SQL Editor → รัน update app_config set edit_password='รหัสใหม่' where id=1;
  • เวอร์ชันนี้ใช้รหัสผ่านรวม (ยังไม่มีบัญชีรายคน) — ผู้ที่มีรหัสจะแก้ไขได้ทุกสาขา ตามที่ตกลงไว้
  • ถ้าแอดมิน 2 คนแก้พร้อมกัน ระบบใช้ “บันทึกล่าสุดทับ” — เหมาะกับทีมเล็ก อัปเกรดภายหลังได้
  • อัปเดตแอปในอนาคต: แก้ไฟล์ index.html แล้วลากขึ้น Netlify ทับได้เลย (ข้อมูลอยู่ที่ Supabase ไม่หาย)
